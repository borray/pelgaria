# Фирменный знак Пельгарии

- `pelgaria-mark-color` — основная иконка для сайта, Discord и социальных площадок.
- `pelgaria-mark-blue` — синий знак на светлом или прозрачном фоне.
- `pelgaria-mark-white` — белый знак для тёмных фонов.
- `pelgaria-mark-black` — чистая чёрно-белая печать и документы.
- `pelgaria-mark-seal` — круглая версия для печатей, документов и аватаров.
- `pelgaria-mark-compact` — упрощённый знак для очень маленьких размеров.
- `pelgaria-lockup-light` — горизонтальный логотип на светлом фоне.
- `pelgaria-lockup-dark` — горизонтальный логотип на тёмном фоне.

SVG подходит для печати и масштабирования. PNG подготовлены для обычного использования.

Знак построен из 13 равных квадратных модулей: центрального блока 3×3 и четырёх элементов, присоединённых к центрам его сторон. Простая геометрия сохраняет узнаваемость в интерфейсе, печати и малых размерах.

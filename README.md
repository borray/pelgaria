# ЭкзаменПРО

Программа для проведения экзаменов: создание КИМ, печать бланков, обработка результатов.

---

## Установка (один раз)

### Шаг 1 — Включите автосборку в GitHub

Зайдите в репозиторий на GitHub → **Settings** → **Actions** → **General**  
Выберите **"Read and write permissions"** → нажмите **Save**.

> После этого программа будет собираться автоматически при каждом изменении кода.

---

### Шаг 2 — Скачайте программу

Перейдите на вкладку **[Releases](../../releases)** в этом репозитории  
и скачайте файл **`ExamApp.exe`**.

Если вкладки Releases пока нет — подождите несколько минут после шага 1  
и обновите страницу. Сборка занимает ~3–5 минут.

---

### Шаг 3 — Запустите

Просто дважды щёлкните по скачанному **`ExamApp.exe`**.  
Никакой установки не нужно. База данных создаётся автоматически рядом с файлом.

> **Windows может показать предупреждение** "Неизвестный издатель" — нажмите  
> **"Подробнее"** → **"Всё равно выполнить"**.

---

## Обновление программы

Когда в код вносятся изменения, в нижней части боковой панели появляется  
жёлтая кнопка **"Установить обновление"**. Нажмите её — программа скачает  
новую версию и перезапустится автоматически.

---

## Что умеет программа

| Раздел | Описание |
|---|---|
| 📚 Банк вопросов | Создание вопросов: одиночный выбор, множественный выбор, развёрнутый ответ |
| 📋 Формирование КИМ | Сборка экзамена из банка, ручное или случайное добавление вопросов |
| 👥 Участники | База участников с группами |
| 🖨️ Печать бланков | Генерация PDF: текст КИМ + бланк ответов для каждого участника |
| 📊 Служебный раздел | Ввод ответов после экзамена, ручная проверка, итоговые результаты |
